# Passenger ferry: credits

All photo-based surface detail comes from ambientCG (CC0 1.0, public domain), sampled per island in real-world metres
by tools/kcompose.py (same ambientCG set as the kiosks):
- Metal009, Metal011: brushed stainless / aluminium (rails, posts, stair, mast, tread plate base)
- Rust004: light tea-staining in occluded steel corners
- PaintedMetal004: paint / gelcoat orange-peel normal, painted surfaces
- Plastic010: life rings, fenders, raft canisters, radar
- Rubber004: rub rail, bench frames' rubber feet
- Wood049: bench slats
- Ground054: non-skid deck grit
- Scratches005, SurfaceImperfections003, Fingerprints002, Smear008: wear, smudges, glass smears

Fonts (lettering drawn by tools/ksigns.py): Lobster, Bebas Neue, Oswald, all SIL Open Font License 1.1.

The vessel is generic and unbranded: no operator name, logo or livery. "Sea Breeze" / "SAN DIEGO, CA" are a made-up boat name and
a generic home port, and "PASSENGER FERRY" is a generic description. All geometry is parametric (tools/f_ferry.py).
